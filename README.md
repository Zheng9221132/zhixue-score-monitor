# 智学网成绩监控/zhixue-score-monitor
智学网成绩监控：零依赖单文件 Python 脚本，轮询考试成绩变化，用于在考后实时查看各科目出分情况并提醒，支持新出分科目提醒（Windows）。

一个零依赖的单文件 Python 脚本，用于监控智学网考试成绩。当所选考试有新成绩发布或成绩发生变化时，脚本会在终端打印结果；如果检测到新增科目，还会弹出 Windows 提示框并播放系统铃声。

---

## 特性

- **零第三方依赖**：仅使用 Python 标准库
- **单文件**：直接运行 `zxw.py` 即可
- **Cookie 本地保存**：首次运行输入一次，之后自动读取
- **自动重新登录提示**：收到 HTTP 400 时自动提示重新输入 Cookie 并重试请求
- **成绩变化检测**：新成绩、成绩更新都会提示
- **新科目提醒（Windows）**：检测到考试新增科目时弹窗 + 响铃
- **轮询间隔自定义**：启动时输入，默认 10 分钟

---

## 环境要求

- Python 3.7 或更高版本
- 操作系统：
  - 成绩监控本身跨平台（Windows / macOS / Linux 均可）
  - **新科目弹窗提醒仅 Windows 支持**（使用 `ctypes` + `winsound`）

## 快速开始

### 1. 获取 Cookie

1. 用浏览器登录 [https://www.zhixue.com](https://www.zhixue.com)
2. 按 `F12` 打开开发者工具
3. 进入 **Network（网络）** 标签页
4. 刷新页面，点开任意一个请求
5. 在 **Request Headers（请求头）** 中找到 `Cookie:` 这一行
6. 复制 `Cookie:` 后面的完整内容

> 也可以在浏览器控制台执行 `document.cookie`，但推荐从 Network 里复制完整请求头，更可靠。

### 2. 运行脚本

```bash
python zxw.py
```

首次运行时会提示：

```
请粘贴新的 Cookie（可包含 Cookie: 前缀）：
```

把上一步复制的 Cookie 粘贴进去并回车，Cookie 会被保存到脚本同目录下的 `zxw_cookie.txt`。

### 3. 设置轮询间隔

```
轮询间隔（分钟，直接回车 = 10）：
```

输入一个大于 0 的数字，或直接回车使用默认值（10 分钟）。

### 4. 选择要监控的考试

脚本会列出最近两个学年内的考试，选择要监控的那场考试即可。

之后脚本会持续运行，发现变化就打印，按 `Ctrl+C` 退出。

| 参数 | 说明 |
| --- | --- |
| `--test` | 测试新科目提醒（弹窗 + 铃声），关闭弹窗即退出 |
| `--rounds N` | 只运行 N 轮后退出，便于测试，例如 `python zxw.py --rounds 1` |

```bash

python zxw.py --test

# 跑一轮就退出
python zxw.py --rounds 1
```

## 生成的文件

脚本会在其所在目录下创建两个文件：

| 文件 | 用途 | 是否可删 |
| --- | --- | --- |
| `zxw_cookie.txt` | 保存你的登录 Cookie | 删除后下次启动会重新提示输入 |
| `zxw_state.json` | 保存已监控考试的成绩指纹，用于判断是否变化 | 删除后第一次运行会把当前成绩作为基线，不提醒 |

> ⚠️ `zxw_cookie.txt` 等同于账号凭据，不要分享或上传到公共仓库。

## 工作原理

1. 调用 `/container/app/token/getToken` 获取 `XToken`，签名算法：
   ```
   md5(guid + timestamp + "iflytek!@#123student")
   ```
2. 调用 `/zhixuebao/base/common/academicYear` 获取学年列表
3. 调用 `/zhixuebao/report/exam/getUserExamList` 获取考试列表
4. 调用 `/zhixuebao/report/exam/getReportMain` 获取某场考试的各科分数
5. 对成绩做 SHA-256 指纹，与 `zxw_state.json` 中的历史记录比较：
   - **首次出现**：记录为基线，不提醒（除非是首次以外的轮次）
   - **指纹变化**：打印新成绩
   - **出现新科目**：在 Windows 上弹窗 + 响铃

## 常见问题

### Q: 收到 HTTP 400，怎么办？

说明 Cookie 已失效。脚本会自动提示重新输入 Cookie：

```
收到 HTTP 400，Cookie 可能已过期。请重新登录网站并输入新的 Cookie；输入后将自动重试请求。
```

重新登录智学网，按前文步骤复制新 Cookie 粘贴进去即可。

### Q: 提示 "新科目提醒仅支持 Windows"

这是设计如此。在非 Windows 系统上检测到新科目时只会打印红色文字提示，不会弹窗。

### Q: 输出是乱码 / 颜色不生效

- 颜色在非 TTY 环境（例如重定向到文件）会自动关闭
- 设置环境变量 `NO_COLOR=1` 可强制关闭颜色
- Windows 上建议使用 Windows Terminal 或 PowerShell 以获得更好显示效果

### Q: 找不到考试列表

- 检查 Cookie 是否有效
- 脚本默认只查最近 `2` 个学年，可以在代码顶部修改 `LOOKBACK_YEARS`
- 每学年最多取 `PAGE_SIZE = 20` 场考试，可在代码顶部修改

### Q: 首次运行会提示"新成绩"，但我想静默建立基线

直接运行一次即可。首次轮询会把当前成绩记作基线，之后的轮次只提示变化。
